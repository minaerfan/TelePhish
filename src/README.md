# Propagation-based Phishing Detection at Telegram – Source Code

This directory contains the source code used for propagation-based phishing detection experiments.  
The code is designed to work with the **TelePhish dataset**, which is stored separately due to its size.

The dataset is available in the **main branch** of this repository.

---

## Dataset Requirement

The dataset is **not included** in this branch.

To run the code in this directory, you must first download the dataset from the **main branch** of the repository.

---

## How to Use the Dataset

1. Switch to the `main` branch of this repository.
2. Download the file `TelePhish.zip`.
3. Extract the ZIP file.
4. Name the file telephish.csv
5. Create a folder named `data`.
6. Place the extracted dataset inside the `data` folder.

The `data` folder must be located at the same level as `src`.
